# Data governance and citation

The repository MIT license applies to repository-authored code and documentation. Every source dataset retains its own license, attribution, access and redistribution requirements. Check the exact product's terms rather than applying a blanket prohibition to all raw data.

For Tribal, community and culturally sensitive data, record the authorized custodian, approved purpose and access process in an appropriate private system. Public availability does not substitute for applicable Tribal guidance. Obtain the required authorization before accessing or sharing governed material. Public records here should contain only approved, non-sensitive descriptions.

For each analysis, retain the product title, authors/provider, release/version, DOI or stable product URL, retrieval date, variables/units, spatial and temporal selections, quality flags, and transformation steps. Use the provider's exact recommended citation for the selected release; do not invent a publication year. Acknowledge OLC NIFA when appropriate to the project or agreement.

Keep credentials, raw downloads, caches, restricted geometry and private endpoints out of Git. Derived products require documented methods and applicable source/governance review before redistribution.
